Setup & access

⏱ 10 min for Day 1🌐 Browser only📅 Before Session 1
⏰ Do this before Session 1

For: Workshop participants
Please complete by: the day before Day 1 for steps 1, 2 and 6 (browser only). Steps 3–5 (Studio Web) are for Lab 4 and can wait until before Day 2
Time needed: about 10 minutes for Day 1, plus about 10 minutes for the Studio Web steps before Day 2

The workshop is hands-on, so every participant needs working access before Session 1 starts. If anything in this guide doesn't work, contact the people listed in section 6 before the workshop day. We won't have time to fix access issues during the session.

📦 What you need

  1. 1
    Automation Cloud account
    Details: On the UiPath workshop tenant. You receive an invitation email from UiPath with the tenant URL and the organization and tenant names.
  2. 2
    IXP access
    Details: Access to the IXP service on that tenant. We give you the IXP Project Creator role on the lab tenant, so you can create your own lab projects
  3. 3
    Orchestrator folder access
    Details: Access to the workshop folder Shared. Used for the Lab 4 workflow and validation tasks
  4. 4
    UiPath Studio Web
    Details: Only for Lab 4 on Day 2. The workshop uses Studio Web on the workshop tenant, in the browser. Nothing to install, and it works on Windows and Mac
  5. 5
    Activity packages
    Details: Only for Lab 4 on Day 2: UiPath.DocumentUnderstanding.Activities (latest stable version), added to your Studio Web project
  6. 6
    Sample documents
    Details: 6 fictional PDFs, from the Resources page of the workshop site

🧰 Before you start

  • Use the work email address that received the tenant invitation.
  • If you work on a customer network or VPN, try the steps from the network you will use on the workshop day.
  • Admin steps (granting roles, enabling services) are done by your trainer on the workshop lab tenant.

🛠 Step-by-step setup

UI labels may differ slightly between product versions.

Step 1 – Sign in to Automation Cloud

  1. Go to the tenant URL in your invitation email (or https://cloud.uipath.com) and sign in with your work account.
  2. If you belong to more than one organization, select the workshop organization.
  3. Select the workshop tenant in the tenant picker.

✅ You see the Automation Cloud home page for the right tenant.

Step 2 – Open IXP

  1. In the left navigation, open IXP.
  2. Create a test project (e.g. test-<your-name>) with the type for unstructured and complex documents, then delete it again. You create your own lab projects during the workshop.

✅ You can open IXP and create a project.

Step 3 – Open Studio Web (for Lab 4 on Day 2 – can wait until after Day 1)

The workshop uses Studio Web, which runs in the browser. You don't need to install Studio desktop.

  1. On the Automation Cloud home page of the workshop tenant, open Studio from the left navigation (names may differ slightly by version).
  2. If you're asked to choose, open Studio Web in the browser (not the Studio desktop download).

✅ Studio Web opens in the browser, signed in to the workshop tenant.

Step 4 – Check the tenant and folder (for Lab 4 on Day 2 – can wait until after Day 1)

  1. Check that Studio Web shows the workshop organization and tenant. If not, switch tenant from the Automation Cloud home page and open Studio Web again.
  2. Open Orchestrator in the browser and check that you can see the folder Shared.

✅ Studio Web is on the right tenant, and you can see the workshop folder.

Step 5 – Add the activity package (for Lab 4 on Day 2 – can wait until after Day 1)

  1. In Studio Web, create a new blank process (e.g. IXP_Workshop_Setup).
  2. Open the project's package manager (Manage packages or Dependencies; names may differ slightly by version).
  3. Add UiPath.DocumentUnderstanding.Activities – latest stable version. (UiPath.IntelligentOCR.Activities is for Windows projects in Studio desktop; you don't need it in Studio Web.)
  4. In the activities list, search for Extract Document Data.

✅ The package is added without errors, and the Extract Document Data activity is available.

Step 6 – Download the sample documents

  1. Open the Resources page of the workshop site and download the 6 sample PDFs.
  2. Save them in one local folder, e.g. IXP_Workshop/Docs.

✅ You have 6 PDFs: 3 bank statements (bank_statement_A/B/C…) and 3 customer packets (customer_packet_1/2/3).

🔧 Troubleshooting

Problem Likely cause What to do
IXP is not in the left navigation The IXP service isn't enabled on the tenant, or your account has no IXP role Ask your tenant admin to enable IXP for the tenant and assign you an IXP role (IXP Project Creator or IXP Service Admin to create projects, or a project role such as IXP Model Trainer)
You see IXP but can't open the lab projects No permission on those projects Ask the project owner or admin to add you to the project
Can't create a project Missing a project-creation role (IXP Project Creator or IXP Service Admin) Ask your admin to assign it, or use the shared lab projects
Studio Web opens on the wrong tenant Signed in with another account, or another tenant was selected Switch to the workshop tenant on the Automation Cloud home page, then open Studio Web again
Workshop folder not visible No Orchestrator folder assignment Ask your admin to add you to the workshop folder
Packages not found or fail to install Searching by the wrong name, or a preview version is required Search for the exact name UiPath.DocumentUnderstanding.Activities. If the trainer says a preview version is needed, include prerelease versions in the package search
Timeouts, sign-in loops, SSL errors Corporate proxy, VPN or firewall Try a different network, or ask IT to allow the UiPath Automation Cloud domains.

💡 On the day: remote hands-on tips

  • Two screens recommended: one for the shared screen, one for your own Studio Web / IXP.
  • Join 5–10 minutes early, using the meeting link in your calendar invite.
  • Camera optional. Please stay on mute unless you're speaking.
  • Ask questions anytime in the chat, or raise your hand. Labs have checkpoints where we wait for everyone.
  • Keep your Studio Web and IXP tabs signed in before the session starts.
  • Have the sample documents unzipped and ready.

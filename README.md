# IXP Hands-on Workshop

Participant site for a short hands-on UiPath IXP (Intelligent Xtraction and Processing) workshop: designing IXP
projects, getting extraction quality right, handling repeating data and multi-document files, and building a lean
workflow with confidence checks and human validation.

**Open the site:** https://uipath-technical-partner-success.github.io/IXP-HandsOnWorkshop/

The site is generated from a private source repo and deployed to the `gh-pages` branch, which holds only the latest
published pages. Please don't open pull requests here; changes made in this repo are overwritten on the next deploy.

# IXP Hands-on Workshop

Hands-on participant site for a hands-on UiPath IXP (Intelligent Xtraction and Processing) workshop: designing IXP
projects, getting extraction quality right, handling repeating data and multi-document files, and building a lean
workflow with confidence checks and human validation.

**Open the site:** https://uipath-technical-partner-success.github.io/IXP-HandsOnWorkshop/

- 4 labs with step cards, checkpoint answers and ready-to-use instructions
- Theory pages in workshop order (theory → lab)
- 6 sample PDFs in `assets/samples/`, plus `lab3_split_parts.zip` (packets 1 and 2 split per document). All names, account numbers and amounts are fictional.
- Progress is saved in your browser only (localStorage).

Static HTML, CSS and JavaScript; no build step. The look follows the
[IXP self-learning course](https://uipath-practice.github.io/IXP-TrainingCourse/index.html).

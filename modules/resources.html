🆕 Recent IXP updates covered in the workshop

Availability can differ per tenant and region. Statuses follow the public UiPath docs (docs.uipath.com ↗); each row links the page that sets its status. Preview features may change before general availability, so check that page again before you commit a customer project to one.

UpdateWhat it doesStatusWhere we use it
IXP in FlowExtract node (fields, confidence and a reference to where each value sits) and Validate extraction node (Validation Station) in Maestro Flow. Validate extraction works only with a model built in the same flow (docs ↗)PreviewFollow-up
IXP models as solution resourcesDeploy a model version to an Orchestrator folder with the To folder option and use it in Flow, Extract Document Data and the DU Project Extractor. The activities need preview package versions (docs ↗)PreviewFollow-up
Coded workflows for documentsThe du service (du.ExtractDocumentData, du.ClassifyDocument) and the PDF coded automation APIs (pdf.<method>) in C# coded workflows (docs ↗)PreviewFollow-up
More input formatsExtract Attachments from PDF and Convert Email/HTML/Text to PDF activities; Create PDF from Images in the PDF coded APIs (docs ↗). Redact Document (IntelligentOCR package, Windows) is already generally availablePreviewNot used in the labs
Evaluation runs (IXP in Flow)In the Flow Extract node you start each evaluation yourself with Run evaluation, optionally on a tagged subset, and compare runs on the Eval runs tab (docs ↗). A standalone IXP project has no run action: scores show on Build and Measure as you annotatePreviewFollow-up
Validation Station improvementsIXP results validated as tables, Confirm All Cells for a whole table, field filters, collapsible field groups, a line number column and frozen columns in wide tables (filters, collapse and freezing in the compact view only) (docs ↗)AvailableLab 4
Model pickerBuild → Model configuration groups models as Available, Preview and Custom (your own subscriptions) and shows the region requests are routed to when a model does not stay in your tenant's region. GPT-5.1, GPT-5.4 and Gemini 3.5 Flash Lite are generally available; the Claude Sonnet models are Preview. Lab 1 uses GPT-4o or Gemini (docs ↗)Available Preview (Claude models)Lab 1
OCR updatesBetter handwriting recognition and lower latency in UiPath Document OCR. A model update can shift confidence distributions, so if you route on OCR confidence, recheck your thresholds (docs ↗)AvailableLab 4
Intelligent pre-processingTable model - mini and Table model prepare tables before the LLM reads the document (docs ↗). The Layout model (extended languages) option is Preview, in the Japan region only (docs ↗)Available Preview (Layout model)Lab 1
Coding agents for IXPA coding agent builds an IXP project from sample documents and refines the instructions, through the uip CLI and the uipath-ixp skill (docs ↗)PreviewOptional lab
Use your own LLM subscription (BYOS)Run IXP on the customer's own Google Vertex AI or Microsoft Azure OpenAI subscriptions; requests still pass through the AI Trust Layer (docs ↗)PreviewNot used in the labs
